**modus** is an independent development lab dedicated to building lightweight, fast, and clutter-free software. Less noise, more focus on what truly matters.

### 📐 Philosophy
Substance over noise: Features exist with purpose, without unnecessary complexity.
Native speed: Responsive interfaces, zero friction, and fluid performance by default.
Continuous design: Geometric typography, balanced contrast, and visual restraint.
